## 🎯 Описание проекта

**MasterX** — это веб-приложение для управления производственными заказами, отслеживания выполнения задач на участках и автоматического расчёта потребности в материалах. Система предназначена для производственных предприятий, работающих с металлообработкой, покраской и сборкой светотехнического оборудования.

### Ключевые особенности
- **Полный цикл управления заказом** — от создания до отгрузки
- **Разделение по производственным участкам** — 5 участков с индивидуальными техкартами
- **Автоматический расчёт материалов** — листовые материалы, профили, прутки
- **Расчёт порошковой краски** — с учётом технологических потерь и RAL
- **Хранение в браузере** — все данные в localStorage, не требует сервера
- **Экспорт в Excel** — выгрузка отчётов для бухгалтерии

## ⚙️ Основные возможности

### 1. Управление заказами
- Создание заказов с выбором изделия, размера, количества
- Выбор кронштейнов и лир с указанием количества
- Назначение RAL (цвет) и текстуры
- Добавление комплектующих деталей
- Импорт/экспорт заказов в JSON

### 2. Отслеживание выполнения по участкам
| Участок | Ключевые операции |
|---------|-------------------|
| 🔧 **Токарный** | Точение, фрезеровка, заготовка |
| 🔨 **Слесарный** | Нарезка резьбы, установка заклепок, обработка, голтовка, УВ |
| ⚙️ **Фрезерный** | Раскрой поликарбоната, фрезеровка ПВХ, заглушек |
| ✨ **Лазерно-гибочный** | Раскрой стали/алюминия, гибка кронштейнов |
| 🧪 **Полимерный** | Сборка, комплектация |

### 3. Отчёт по материалам
- **Листовые материалы** — алюминий, сталь, нержавейка, ПВХ, поликарбонат
- **Профили** — длина каждого профиля в мм
- **Прутки** — диаметр и общая длина
- **Порошковая краска** — расчёт с учётом:
  - Нормы расхода по RAL (0.165 кг/м² по умолчанию)
  - Технологических потерь (плоские +10%, профили +20%, трубы +30%)
  - Округления до 0.5 кг

### 4. Управление задачами на участках
- Навигация по датам (вчера/сегодня/завтра)
- Добавление исполнителей на задачу
- Учёт количества выполненных деталей
- Закрытие смены для исполнителя
- Фильтрация по статусу (ожидает/в работе/завершено)
- Экспорт в CSV/Excel

## 🚀 Установка и запуск

### Системные требования
- Любой современный веб-браузер (Chrome, Firefox, Safari, Edge)
- Для работы не требуется сервер (всё локально)

### Установка
1. **Скопируйте файлы проекта** в любую папку на компьютере
2. **Убедитесь**, что структура папок сохранена (см. выше)
3. **Откройте** `index.html` в браузере

### Первый запуск
1. На главной странице нажмите **«Новый заказ»**
2. Заполните форму:
   - Дата заказа
   - Номер заказа (генерируется автоматически)
   - Изделие и размер
   - Количество
   - Кронштейн/лира (при необходимости)
   - RAL и текстура
3. Нажмите **«Создать заказ»**
4. Заказы автоматически появятся на главной странице

### Работа с участками
1. На главной странице нажмите на нужный участок (Токарный, Слесарный и т.д.)
2. Выберите дату (вчера/сегодня/завтра)
3. Для каждой задачи:
   - Добавьте исполнителя
   - Укажите количество
   - Нажмите «НАЧАТЬ» → статус «В РАБОТЕ»
   - После выполнения → «ЗАКРЫТЬ СМЕНУ» или «ГОТОВО»

## 🛡 Администрирование

### Настройка норм материалов

Все нормы хранятся в `data/norms.json`:

```json
{
  "aluminum": [
    { "product": "XGRAY v.1", "thickness": "3мм", "area": 0.0032 }
  ],
  "steel": [...],
  "pvc": [...],
  "polycarbonate": [...]
}
Настройка правил покраски
Файл data/paintingRules.json определяет, какие детали красятся:

json
{
  "XEYES 130*120 4": {
    "components": {
      "Алюминий 2мм": true,
      "Поликарбонат 3мм": false
    }
  }
}
Добавление нового изделия
Добавить в data-loader.js:

javascript
{ name: 'НОВОЕ_ИЗДЕЛИЕ', sizes: ['Размер1', 'Размер2'] }
Добавить нормы в norms.json:

json
"aluminum": [..., { "product": "НОВОЕ_ИЗДЕЛИЕ", "thickness": "3мм", "area": 0.005 }]
Добавить правила покраски в paintingRules.json:

json
"НОВОЕ_ИЗДЕЛИЕ": {
  "components": { "Алюминий 3мм": true }
}
Добавить прутки в rodsByProduct.json (если есть):

json
"НОВОЕ_ИЗДЕЛИЕ": {
  "rods": [{ "name": "Пруток 50мм Д16Т", "diameter": 50, "length": 80, "area": 0.01257 }]
}

❓ Часто задаваемые вопросы
Q: Где хранятся данные?
A: Все данные хранятся в localStorage браузера. При очистке истории браузера данные будут потеряны. Рекомендуется регулярно экспортировать заказы.

Q: Можно ли работать на разных компьютерах?
A: Данные не синхронизируются автоматически. Используйте экспорт/импорт для переноса.

Q: Как добавить новое изделие?
A: См. раздел «Администрирование» → «Добавление нового изделия».

Q: Почему не считается краска?
A: Проверьте, что в paintingRules.json для изделия указано "Алюминий Xмм": true.

Q: Как изменить норму расхода краски?
A: В norms.json в секции paint измените defaultConsumptionPerM2.

Q: Можно ли изменить коэффициенты потерь?
A: Да, в paintCalculation.json в секции lossCoefficients.
